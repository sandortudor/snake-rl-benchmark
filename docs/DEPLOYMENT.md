# Deployment measurements

Generated by:

```bash
python -m snake_rl.benchmark_resources \
  --runs runs/full_2000_tuned \
  --iterations 1000 \
  --out reports/full_2000_tuned/deployment_metrics.csv
```

The canonical CSV records checkpoint bytes and action-selection latency for seed
1 on CPU. On the measured Apple Silicon environment, the Lightweight DDQN
checkpoint is 42,037 bytes, compared with 145,205 bytes for Dueling DQN. Median
action-selection latency was approximately 27 μs for Lightweight DDQN and 35 μs
for Dueling DQN.

Latency measurements are not universal benchmarks. Quote them only together with
the `device`, `python`, `machine`, `system`, warm-up, and iteration settings.
